# Локальная генерация через студию

Используй этот способ, когда пользователь просит **генерировать через Local Image Studio / Nano Banana из студии**. Нужен доступ к тому же компьютеру, где работает `node server.mjs`. Это не замена встроенного генератора во всех чатах и не облачный API.

Пользователь выбирает профиль в браузере и нажимает «Разрешить помощнику использовать этот профиль». Не включай доступ сам, не извлекай API-ключи из браузера и не проси присылать их в чат.

## Проверка без генерации

Из папки студии:

```sh
node scripts/studio-assistant.mjs status
```

Из другого проекта используй абсолютный путь к этому скрипту. Если `enabled: false`, попроси пользователя нажать кнопку разрешения в студии. Если студия остановлена, попроси её запустить. Проверка не тратит баланс.

## Генерация

Только по запросу пользователя, учитывая, что провайдер может списать деньги:

```sh
node scripts/studio-assistant.mjs generate --prompt "Soft painted forest background, no text" --aspect 16:9 --resolution 1K --output "assets/forest.png"
```

Для длинного текста или промпта с кавычками удобнее `--prompt-file path/to/prompt.txt`. Не вставляй непроверенный текст в оболочку: передавай аргументы без shell-интерполяции или используй файл.

Дополнительные параметры:

- `--prefix "стиль"`, `--negative "чего избегать"`;
- `--reference path/to/image.png` (повторяется до пяти раз, PNG / JPEG / WebP, до 8 МБ каждый; только явно выбранные для задачи файлы);
- `--size 1024x1024`, `--quality high` для совместимых API.

По умолчанию берутся модель, провайдер, endpoint, прокси и параметры **разрешённого снимка профиля**. Ни сцена, ни стиль, ни референсы из браузера не добавляются автоматически. NovelAI использует свои параметры и негатив из профиля; `--negative` может переопределить негатив. Референсы NovelAI нужно отправлять через интерфейс студии, где подготавливаются размеры.

Команда возвращает небольшой JSON с `filePath`, моделью и типом картинки, не печатает ключи, промпт или base64. Результат также архивируется в `generated-images/`; браузерная история IndexedDB не пополняется автоматически. При другом формате ответа расширение файла корректируется под MIME. Существующие файлы не перезаписываются.

Не повторяй платный запрос автоматически при ошибке, таймауте или потере соединения: провайдер уже мог выполнить генерацию. Остановка команды / отключение доступа прекращает ожидание, но не гарантирует отмену удалённой задачи или возврат средств.

## Границы доступа

- По умолчанию всё выключено. Разрешение действует до отключения или перезапуска сервера; обновление страницы браузера его не отменяет.
- Разрешён только один снимок профиля. Изменение настроек в браузере не меняет его молча: пользователь обновляет доступ кнопкой.
- Одновременно выполняется один запрос помощника, не более 20 за скользящий час, включая неудачные попытки. В каждом запросе одна картинка; автоматических повторов нет. Это локальное ограничение, не финансовый лимит на стороне провайдера.
- Скрипт сам читает `.assistant-access/connection.json`. **Не читай, не выводи и не копируй этот файл в чат или Git.** В нём локальный ключ доступа, а не ключ генерации. Ключ провайдера и пароль прокси остаются в памяти сервера.
- Это защита от случайного доступа других веб-страниц, не изоляция от программ с полным доступом к той же учётной записи компьютера.
- Без MCP, туннеля и внешней публикации: HTTP слушает только `127.0.0.1`. Скрипт отказывается посылать локальный ключ на другой хост или по redirect.
